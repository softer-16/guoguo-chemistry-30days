# 果果的化学·30天通关系统

面向零基础九年级学生的化学学习网站。当前首批开放 Day 01–Day 03，包含逐日学习顺序、分考点练习、提示阶梯、错题复习、家长验收和本地学习记录。

## 在线访问

<https://softer-16.github.io/guoguo-chemistry-30days/>

## 使用

直接打开 `index.html`，或在本目录启动静态文件服务器：

```powershell
python -m http.server 4173
```

浏览器访问 <http://127.0.0.1:4173/>。

## 数据与版权

- 学习记录只保存在当前浏览器，可手动导出/导入 JSON。
- 网站不包含教材或教辅扫描页。
- 知识讲解与题目依据人教版九年级上册课程范围重新组织，题目为原创或改编表达。
